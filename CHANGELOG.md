#### Version: 3.4.0

##### Features：

Android&iOS: Added playback progress callback feature.
Android&iOS: Improved playback success rate and overall stability.
Android: Log output is now disabled by default.
Android: Fixed fallback playback failure in specific scenarios.
iOS: Reduced memory usage when playing high-resolution TEPG animations.
iOS: Fixed an issue where the Play End event was not received on certain devices during animation playback.
iOS: Fixed blurry playback issue for high-resolution TEPG animations.

- Support playback of ordinary and encrypted special effect resources.
